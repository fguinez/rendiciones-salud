# Commits and PRs

- Gitmoji + Sentence-case English title, ≤ 72 characters, imperative mood:
  `🐛 Return a lista rendición to borrador when an edit leaves it incomplete`.
- One logical change per commit; stage explicit paths.
- PR titles and descriptions follow the same language and privacy rules: describe behaviour,
  use placeholders, never real amounts, ids, names or health details
  (`rules/security.md`).
- Images in PRs come only from the fake demo server (`context/commands.md`).
